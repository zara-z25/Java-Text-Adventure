# Java Text-Based Adventure Game

A multi-file text-based adventure game in Java inspired by classic interactive fiction (e.g., Zork). Players navigate rooms, solve puzzles, manage an inventory, and track scores through text commands.

## Features
- Text-based navigation through multiple rooms
- Inventory management and puzzles
- Dynamic map display of explored areas
- Custom commands to enhance gameplay
- Fully implemented using Object-Oriented Programming principles

## Skills Applied
- Java programming
- Object-Oriented Programming (OOP)
- Algorithmic Thinking
- Data Structures
- Modular software design

## How to Run
1. Navigate to the `src` folder
2. Compile all `.java` files:

javac *.java
